# Book & Author Management System

This is a simple Laravel backend project to manage Authors and their Books.
The system includes basic CRUD operations, proper Eloquent relationships,
and request validation, as per the assignment requirements.

---

## 🚀 Features
- Create, Read, Update, Delete (CRUD) Authors
- Create, Read, Update, Delete (CRUD) Books
- One-to-Many relationship between Author and Books
- Request validation using Laravel validation
- Clean and readable Laravel MVC structure
- Simple Blade views with Bootstrap styling
- No authentication (as not required)

---

## 🛠️ Tech Stack
- PHP 8+
- Laravel 10
- MySQL
- Blade Templates
- Bootstrap 5
